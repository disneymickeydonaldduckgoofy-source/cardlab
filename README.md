# Card Lab Launcher

名刺管理アプリ「Card Lab」をスマホのホーム画面から開くための入口ページです。

- ホーム画面のアイコンから起動すると、Card Lab（claude.ai のアーティファクト）へ自動で移動します。
- ブラウザで直接開いた場合は移動せず、ホーム画面への追加方法を表示します。
- アイコンを差し替えるときは、ファイル名の番号を上げてください（例: `cl1-` → `cl2-`）。同じ名前のままだと端末側で古いアイコンが残ります。

- manifest.webmanifest の id は `/cardlab/` のように、このリポジトリ専用の住所にしてください。`./` にすると同じサイトのほかのラボと同じアプリ扱いになり、インストール時に上書きされます。
